# Security Policy

SentinelOps AI is a portfolio demonstration and must not be used with real credentials, secrets, regulated data, or confidential production logs.

Implemented controls include environment-based secrets, file type and size validation, deterministic offline operation, visible tool evidence, and read-only analytical workflows.

Production use would require authentication, RBAC, tenant isolation, malware scanning, immutable audit logs, secrets management, rate limiting, prompt-injection defenses, SIEM integration, secure model governance, and formal threat modeling.
